# bqdp
Domain agnostic sequential recommendation over an integer universe. Every item is an
integer id in `[1, N]`, the system never learns what an item represents, and prediction
is framed as next-item selection conditioned on the observed history.





## Measurement first
Quality claims are meaningless without a ceiling to measure against. The bundled test
derives the analytic optimum of its own generating process and prints `gap_to_oracle` on
every run, so any distance from the optimum is attributable to the implementation rather
than to the data. Reproduce that discipline for your own stream before tuning anything.

Metrics come in two forms. Lifetime averages cover the entire run including the cold
start, which permanently understates a converged system. `recent_recall_at_k` and
`recent_mean_rank` cover a trailing window and are the numbers to compare against the
ceiling.





## Experts
Four predictors run in parallel and their outputs are combined as a linear mixture.

**Variable order Markov.** Directed successor counts over contexts of length `1..order`,
interpolated with absolute discounting and backed off to unigram frequency. For a stream
generated by a Markov process this expert is a consistent estimator of the process
itself. Contexts are bounded by an LRU policy and successors are pruned per row, so cost
is `O(order * row + order * N)` per prediction.

**Sequence model.** A causal transformer over the item sequence, with learned positional
embeddings and input/output weight tying, following SASRec. Padding is left aligned and
masked out after every block. Training uses a full softmax while the universe is small
and a shared-negative sampled softmax above `4096` items.

**Co-occurrence.** Directed edges from every item inside the trailing window to the item
that followed it. Storage is sparse with bounded neighbours per row, and decay is applied
through a global scale factor with periodic renormalization.

**Recency.** Exponentially decayed item frequency, maintained incrementally as
`score <- exp(-decay) * score + onehot(item)`, which is exactly equivalent to the
exponential sum over positions but costs `O(N)` per event instead of `O(T)` per
prediction.





## Mixing
Experts are combined linearly, not as a product. A linear mixture bounds the blended
probability below by each weighted component, so a miscalibrated expert can degrade the
result but can never veto a correct candidate the way a conjunction can.

Weights are learned online by the Bayesian update `w <- w * p(observed)`, renormalized,
with a fixed share step that keeps dormant experts recoverable under drift. This carries
the standard guarantee of prediction with expert advice: cumulative log loss exceeds that
of the best single expert by a bounded amount over the whole run. The practical
consequence is that a useless signal collapses to the weight floor instead of silently
degrading predictions, and `evaluate()` exposes both the weights and the per expert mean
log loss so that failures have an address.

Every confirmed selection triggers one gradient step. There is no separate retraining
phase. Experience replay over windows sampled from the stored history mitigates the
catastrophic forgetting of pure online SGD.





## Candidate sets
`predict(k)` returns a fixed size top-k list. `predict_set(alpha)` returns a variable size
set calibrated by adaptive conformal inference against a miscoverage budget. Set size is
the informative diagnostic: it contracts as the blended distribution sharpens, so a
collapsing `mean_set_size` at constant `empirical_coverage` is direct evidence that the
system is gaining confidence rather than merely getting lucky.

## Parameters
| Parameter | Description | Default |
|---|---|---|
| `n` | Universe size, items are integers `[1, n]` | required |
| `k` | Number of candidates returned by `predict` | required |
| `embedding_dim` | Item and position embedding width | `64` |
| `num_layers` | Transformer blocks | `2` |
| `num_heads` | Attention heads, must divide `embedding_dim` | `2` |
| `feedforward_dim` | Inner width of the feed forward block | `256` |
| `dropout` | Dropout on embeddings and attention | `0.2` |
| `max_sequence_length` | Context window fed to the encoder | `128` |
| `learning_rate` | AdamW learning rate | `1e-3` |
| `weight_decay` | Decoupled weight decay | `1e-2` |
| `batch_size` | Replay windows per online step | `32` |
| `steps_per_update` | Gradient steps per observed event | `1` |
| `negative_samples` | Sampled softmax negatives, `-1` selects automatically | `-1` |
| `replay_capacity` | Retained history length | `200000` |
| `decay` | Exponential decay rate for the recency expert | `0.1` |
| `window` | History window for co-occurrence | `5` |
| `cooccurrence_decay` | Decay applied to stored co-occurrence mass | `0.0` |
| `max_neighbors` | Retained neighbours per co-occurrence row | `64` |
| `markov_order` | Longest context used by the Markov expert | `4` |
| `markov_discount` | Absolute discount subtracted from each count | `0.75` |
| `markov_max_contexts` | LRU bound on stored contexts | `200000` |
| `markov_max_successors` | Retained successors per context | `64` |
| `model_weight` | Initial weight of the sequence expert | `0.25` |
| `markov_weight` | Initial weight of the Markov expert | `0.25` |
| `temporal_weight` | Initial weight of the recency expert, alias `alpha` | `0.25` |
| `cooccurrence_weight` | Initial weight of the co-occurrence expert, alias `beta` | `0.25` |
| `mixture_temperature` | Exponent applied to the likelihood in the weight update | `1.0` |
| `mixture_share` | Mass redistributed uniformly each step | `0.005` |
| `mixture_floor` | Lower bound on any expert weight | `1e-4` |
| `conformal_alpha` | Target miscoverage of `predict_set` | `0.05` |
| `conformal_step_size` | Adaptation rate of the online conformal level | `0.01` |
| `evaluation_k` | Cutoff used by the streaming metrics | `10` |
| `autosave_interval` | Updates between automatic checkpoints, `0` disables | `100` |
| `device` | `auto`, `cpu`, `cuda` or `mps` | `auto` |
| `state_dir` | Directory where model state is persisted | `~/.bqdp/default` |

Initial mixture weights are normalized internally and are only a prior, the online update
overrides them as evidence accumulates.
